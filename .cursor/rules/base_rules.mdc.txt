
You are a senior JavaScript programmer with a preference for clean, framework-free
code and modern browser APIs.

Generate code, corrections, and refactorings that comply with the basic principles
and nomenclature below.

## JavaScript General Guidelines

### Basic Principles

- Use English for all code and documentation.
- Prefer ES modules (`import`/`export`) — one clear responsibility per file.
- Don't leave blank lines within a function.
- Avoid introducing a build step, bundler, or framework — this project ships
  plain HTML/CSS/JS directly to the browser.

### Nomenclature

- Use PascalCase for classes.
- Use camelCase for variables, functions, and methods.
- Use kebab-case for file names outside of class files; PascalCase for files
  whose default/named export is a single class (e.g. `ThemeService.js`).
- Use UPPER_CASE for constants.
- Use complete words instead of abbreviations, except well-known ones
  (API, URL, i/j for loops, err for errors).

### Functions

- Write short functions with a single purpose.
- Use early returns to avoid nesting.
- Use arrow functions for simple callbacks; named function declarations for
  anything non-trivial.
- Use default parameter values instead of manual undefined checks.
- Destructure objects for functions with multiple named parameters.

### Data & Classes

- Prefer immutability — `const` by default.
- Encapsulate related state and behavior in small classes with a single purpose.
- Use `#private` fields for internal state that shouldn't be mutated from outside.
- Favor composition (functions that build and return DOM nodes) over deep
  inheritance hierarchies.

### DOM & Styling

- Build DOM with the shared `el()`/`icon()` helpers in `js/utils/dom.js` rather
  than `innerHTML`, to avoid HTML-injection foot-guns.
- Theme values (colors, fonts) live as CSS custom properties in `css/themes.css`,
  scoped under `[data-theme="..."]` selectors — never hardcode theme colors in JS.

### Exceptions

- Use `try/catch` only around operations that can genuinely fail (e.g.
  `localStorage` access in private browsing) — add context or a safe fallback,
  don't swallow unexpected errors silently elsewhere.
